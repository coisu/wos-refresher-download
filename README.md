# wos-refresher-download

Whiteout Survival 연맹총동원 새로고침을 도와주는 프로그램 **WOS 새로고침봇**의 배포용 저장소입니다. 이 저장소에는 소스 코드가 없으며, 완성된 앱만 [Releases](../../releases)에 올라옵니다.

## 다운로드

**[최신 버전 받기](../../releases/latest)** 에서 내 컴퓨터에 맞는 파일 하나만 받아 주세요.

| 내 컴퓨터 | 받을 파일 |
|---|---|
| Apple Silicon Mac (M1 ~ M4) | `WOS-mac-apple.zip` |
| Intel Mac | `WOS-mac-intel.zip` |
| Windows | `WOS-windows.zip` |

## 처음 실행하는 방법

**Mac**
1. 받은 zip을 더블클릭하여 압축을 풉니다.
2. 터미널을 열고 `xattr -dr com.apple.quarantine ` 까지 입력합니다(마지막에 띄어쓰기 한 칸).
3. 압축을 푼 앱을 터미널 창으로 끌어다 놓고 Enter를 누릅니다.
4. 이제 앱을 열어 주세요.

**Windows**
1. 받은 zip을 우클릭하여 **모두 압축 풀기**를 합니다.
2. 풀린 폴더 안의 `WOSRefreshBot.exe`를 실행합니다. 폴더 안의 파일들은 함께 있어야 하므로 exe만 따로 옮기지 말아 주세요.
3. SmartScreen 경고가 나오면 **추가 정보 → 실행**을 눌러 주세요.
4. 삼성 휴대폰은 Samsung USB Driver가 설치되어 있어야 인식됩니다.

## 휴대폰 준비

- 개발자 옵션에서 **USB 디버깅**을 켜고 USB로 연결한 뒤, 휴대폰에 뜨는 허용 창에서 허용해 주세요.
- 처음에는 **시험 모드**로 먼저 동작을 확인한 뒤 사용해 주세요.
